# 本机工作台使用

2026-11-15已配置并启动当前Windows电脑的完整离线环境，沿用已有账号与项目数据。入口：[打开工作台](http://127.0.0.1:5173/)。当前聊天中的浏览器已登录原有体验账号。

桌面有两个入口：

- **启动跨境视觉工作台**：重启电脑后双击；本机私有启动器检查并启动项目数据库、队列、存储及四个应用组件，待网页/API就绪后打开浏览器。已启动的组件会保留，不重复创建。窗口可能短暂显示或最小化，初次启动需等待。
- **打开跨境视觉工作台**：服务已运行时直接打开网页，不负责启动服务。

如退出登录或换浏览器，可在本项目`.local/account.json`查看已有体验账号。该文件只留本机，不上传仓库。网页内点击“试用指引”按步骤操作；出现问题可用“记录反馈”下载本机JSON。

当前是offline流程试用，不调用真实付费模型。真实PG/MQ/S3已运行；真实模型接线和IMG-001画质改进仍分别记录。没有配置开机自动运行，也没有开放外网访问。启动器不自动初始化、清空或迁移数据库；后续代码需要新迁移时单独处理。
