# 最小真实供应商验收的离线预检

`python scripts/provider_smoke.py --config work/private-smoke/review.json --preflight` 只检查授权范围和样本，不读取模型密钥、不请求供应商、不创建业务任务。返回 `SCOPE_REVIEW_READY` 仅表示配置可供审阅，不是费用授权，也不是 `PROVIDER_VERIFIED`。省略 `--preflight` 固定返回 `WAITING_EXTERNAL`/exit3；当前没有启用付费执行入口。

将 `ops/provider-smoke.example.json` 复制到忽略的私有目录后编辑。示例故意过期、摘要为占位值、样本不存在；金额只是格式示例，不是供应商价格。配置不允许 API key 或其他额外字段。实际密钥不应进入配置、命令行、Git 或公开报告。

配置固定授权ID、审阅人、UTC起止时间（最多24小时）、源文件路径和SHA-256、完整生成参数/保护矩形和平台目标、精确模型、各一次生成/检测调用上限、USD各步骤及合计上限。金额必须是正定点十进制字符串，合计不得小于两个步骤上限之和；浮点数、科学记数法、布尔调用数、重复JSON字段及范围扩张均拒绝。规范化配置摘要随请求和预算变化而变化，后续执行必须绑定已审阅摘要，不能只凭文件名引用可变配置。

预检读取有界样本，校验原始字节摘要，再经现有受资源限制的独立解码进程确认已是canonical PNG。pixel_exact输出尺寸必须与源一致，源矩形不得越界；BFL请求构造使用已验证内联图像字节，配置不能将localhost或私有S3 URL当作供应商图片输入。公开结果只含摘要、尺寸、模型、调用及金额上限、到期时间；错误仅输出类型，不回显配置或Pydantic输入。

尚未完成：把费用上限与持久调用意图原子绑定、实时Worker路由、已知ID只查询恢复、一次性费用执行及完整归档/回贴/最终检测/费用交叉验收。配置中的金额不能证明供应商收费封顶；还需可核验价表与成本来源，BFL credits不能直接当USD，Gemini未知费用不能当0。超时/未知必须停止新submit并保留预算占用，不能因预检成功就绕过这些条件。当前工程AGENTS禁止实际付费调用，保持这一限制。
